# [BRAND] — Creator Outreach Templates

**Owner:** Founder (sender identity matters — outreach comes from the founder's personal account/inbox, not a brand alias)
**Last updated:** 2026-07-08
**Works with:** `gifting-sop.md` + `seeding-tracker.csv` (statuses: to_review / to_contact / contacted / agreed / shipped / posted)

---

## Ground rules (read before sending anything)

1. **Gift, no strings.** We send a piece. We never demand a post, a script, a date, or a tag. If they post, wonderful. If they don't, we eat the cost — that's the model (see cost model in `gifting-sop.md`).
2. **Personalise or don't send.** Every first-touch must reference something real and specific from their content. If you can't fill `[recent post reference]` honestly in 60 seconds of scrolling, they're not a fit — move them back to `to_review`.
3. **One creator, one thread.** All follow-ups reply in the same DM thread / email thread. Never cold-restart.
4. **Max 3 touches.** First-touch → follow-up 1 → follow-up 2 (soft close). Then stop. Silence is an answer.
5. **Never mention discounts.** Their code is a **gift-with-purchase for their audience** ("founding-customer gift"), not % off. If a creator asks for "a discount code for my followers," explain the fair-value model (script below).

---

## Attribution setup (do this before first-touch)

Each creator gets, at the moment they say yes:

- **Vanity code:** their first name, uppercase (e.g. `MAYA`). Collisions: add last initial (`MAYAK`).
- **Vanity URL:** `[brand].com/maya` → redirects to shop with code pre-applied.
- **What the code does:** unlocks the **founding-customer gift-with-purchase** (see `gifting-sop.md` → GWP spec) — *never a percentage discount*. Price integrity is the brand.
- **Tracking:** code + URL are logged in `seeding-tracker.csv` when status flips to `agreed`, so every attributed order maps to one creator.

## 6. What we NEVER do

- **No script demands.** Never send talking points, mandatory phrases, shot lists, or "please say IGI-certified." Their voice or nothing.
- **No posting obligations on gifts.** A gift with a required post is a fee dressed up as a present. We don't do it.
- **No engagement pods, no comment groups, no follow-for-follow, no bought engagement.** Ever.
- **No usage-rights grabs.** We never bury content-rights language in a gifting message or claim rights because "we sent product." If their content performs and we want to use it, we **ask and we pay** (see re-engagement play).
- **No % discount codes.** Not for creators, not for their audiences, not "just this once." Gift-with-purchase only — fair value is the brand.
- **No pressure after a no,** and no more than 3 total touches after silence.
- **No fudging disclosure.** We proactively *ask* creators to disclose (#gifted / "ad" per FTC + UK ASA rules). We never suggest hiding the relationship, and we never imply disclosure "hurts the vibe."
- **No fake scarcity or fake personalisation.** Templates get filled with true, specific things or they don't get sent.
