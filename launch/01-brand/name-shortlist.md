## Recommendation: **SELIENNE**

**selienne.com — confirmed available. No class-14 trademark hits. No exact social handles found in use.**

Pronounced *seh-lee-EN*. Built from **Selene**, the Greek moon goddess, with the French feminine
suffix **-ienne** (as in *Parisienne*). It is an invented word that still *feels* found — lunar,
feminine, quietly expensive — which is exactly the register of a quiet-luxury, self-purchase brand.

Why it wins:

1. **Only finalist that is clean on every axis.** Exact .com unregistered, zero jewelry/class-14
   conflicts surfaced, and no exact-match Instagram or TikTok accounts appeared in indexed search.
2. **Meaning without genericness.** The moon read (Selene) gives the brand a story — light that is
   real, not manufactured sparkle — that maps onto the "real gold, real diamonds, fair value"
   narrative without using any banned category words.
3. **Travels well.** Reads naturally in French (*sé-lienne*), and the *-ienne* ending is familiar
   enough in US/UK markets (julienne, Parisienne) that pronunciation converges quickly. No awkward
   meanings in FR/DE/IT/ES.
4. **Ownable.** Invented spelling = strong inherent distinctiveness for trademark purposes
   (fanciful/arbitrary mark), unlike dictionary-adjacent names such as Novelle, which is already
   crowded — and in fact conflicted — in class 14.

Main watch-out: spelling drift (*Celienne / Seliene*) after hearing it aloud. Mitigate by buying
the 1–2 obvious misspell domains defensively (see checklist) and always writing the name out in
audio/video ads.

Runner-up: **Caelenne** (equally clean, but the *Cae-* opening has worse spell-after-hearing
behavior in the US). Use it as the fallback if hand-verification of Selienne handles fails.

## Methodology Note — read before relying on any single check

- **Domain checks.** The intended method (Verisign RDAP, 404 = available) was blocked from this
  environment: the session's egress proxy denies rdap.verisign.com, and Verisign's RDAP endpoint
  itself returns 403 to server-side fetchers. Substituted method: **NS-record queries direct to
  public resolvers (8.8.8.8, cross-checked 1.1.1.1 / 9.9.9.9)**. NXDOMAIN from the .com zone =
  the name is not delegated = unregistered; NOERROR = registered. The resolver was validated as
  honest with known-registered and known-fake controls, and NS-level checks were used (not just
  A-records) so parked-but-unresolved domains are correctly reported taken — this caught
  orena.com, which looks free on an A-record check but is registered. This method is reliable but
  is a point-in-time snapshot: **re-verify at the registrar at purchase time** (a domain can be
  registered by someone else the same day; NXDOMAIN also cannot distinguish "never registered"
  from "registered minutes ago with no nameservers yet").
- **Social handles.** Direct probes were impossible: Instagram and TikTok returned HTTP 403 to
  automated clients even for known-existing profiles (@mejuri), so status codes could not
  distinguish free from taken. Handle signal above is from **indexed web search only** —
  no exact-match accounts surfaced for the two finalists — and is **indicative, not
  confirmation**. Login walls and de-indexed private accounts can mask an existing handle.
  Hand-verify in a browser (see checklist).
- **Trademark.** Web-search knock-out only, one query per finalist, US/UK-visible brands. This is
  a **preliminary knock-out screen, not legal clearance**. It catches obvious in-category
  conflicts (it killed Novelle) but cannot catch registered-but-unused marks, phonetic-equivalent
  registrations, or EU/WIPO filings. Full USPTO + EUIPO + UKIPO search, ideally counsel-reviewed,
  is required before committing money to the name.

## Founder's 30-Minute Final Clearance Checklist

Do all of this in one sitting, in this order. The point of the same-hour rule: the moment you buy
the domain, the name becomes visible in zone files and drop-catch feeds — register the social
handles before squatters do.

**Minutes 0–10 — verify, then buy the domain**
- [ ] In a registrar search (Cloudflare/Porkbun/Namecheap), confirm **selienne.com** still shows
      available. If gone, fall back to **caelenne.com** and rerun this list.
- [ ] Buy **selienne.com** immediately (enable WHOIS privacy + auto-renew, 2FA on the registrar
      account).
- [ ] Same cart, defensive: **selienne.co**, **celienne.com** (top misspelling). Optional if
      budget allows: selienne.shop, seliennejewelry.com.

**Minutes 10–20 — USPTO + EU/UK knock-out**
- [ ] USPTO full search: tmsearch.uspto.gov → search "selienne" AND phonetic near-forms
      ("celienne", "selien", "selienn", "seliane") in **class 14** (jewelry) and class 35 (retail
      services). Any live application/registration in class 14 = stop, escalate to counsel.
- [ ] EUIPO (euipo.europa.eu, eSearch) and UKIPO (search-for-trademark.service.gov.uk): same
      strings, class 14. You sell into UK/EU — these registers matter as much as USPTO.
- [ ] Screenshot every empty result page (date-stamped evidence of good-faith search).
- [ ] Book a 30-min trademark attorney consult this week for a real clearance opinion and to file
      an intent-to-use application in class 14 — the search above is a knock-out, not clearance.

**Minutes 20–30 — lock the handles (same hour as the domain purchase)**
- [ ] Instagram: verify **@selienne** free in a logged-in browser, register it. If taken by an
      inactive account, register **@selienne.jewelry** or **@wearselienne** and note IG's inactive
      username policy for later.
- [ ] TikTok: register **@selienne** (same fallback pattern).
- [ ] Pinterest: register **selienne** (business account — Pinterest matters for this customer).
- [ ] Same sweep while you're at it: YouTube handle, X, and the free-tier Shopify store name;
      create a placeholder "coming soon" bio on each so the accounts don't look abandoned.
- [ ] Store all credentials in a password manager; add brand email (hello@selienne.com) as the
      recovery address once the domain's mailbox is live.
